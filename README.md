## Architecture & Privacy

- **Client-Side Execution:** Code runs directly in the user's browser runtime.
- **Privacy First:** No files, calculation inputs, or personal metadata are transmitted to or stored on backend servers.
- **Standards Compliant:** Pure HTML5, CSS3, ES6 JavaScript, and native Web APIs.
